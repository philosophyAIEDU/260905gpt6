물리 놀이터 3D — 실행 안내
============================

[가장 간단한 방법: Netlify에 배포한 주소로 접속]
배포된 사이트 주소를 Chrome 또는 Edge에서 열면 바로 사용할 수 있습니다.
방문자는 Python이나 프로그램을 설치할 필요가 없습니다.

[Netlify에 GitHub 저장소 연결하기]
1. https://app.netlify.com 에 로그인합니다.
2. Add new project → Import an existing project → GitHub를 선택합니다.
3. philosophyAIEDU/260905gpt6 저장소를 선택합니다.
4. netlify.toml에 저장된 설정이 적용됩니다. 직접 입력해야 한다면:
   Branch: main
   Base directory: physics-playground-3d
   Build command: 비워 두기
   Publish directory: . (점 한 개)
5. Deploy를 누릅니다. 완료되면 표시되는 사이트 주소를 엽니다.
6. 이 저장소에 연결해 두면 이후 GitHub 변경도 배포에 반영됩니다.

[내 컴퓨터에서 실행하려면]
1. GitHub 저장소의 Code → Download ZIP을 눌러 다운로드합니다.
2. ZIP의 압축을 풀고 physics-playground-3d 폴더를 엽니다.
3. Windows: 실행하기.bat를 두 번 클릭합니다.
   Mac: 실행하기.command를 두 번 클릭합니다.
4. 검은 창이나 터미널이 뜨면 닫지 말고 그대로 두세요.
5. 브라우저에서 http://localhost:8000 을 엽니다.
   자동으로 열린 페이지가 처음에 오류를 보이면 새로고침합니다.
6. 끝낼 때는 검은 창에서 Ctrl+C를 누릅니다.

Python이 없다고 나오면 https://www.python.org/downloads/ 에서 Python 3를
설치한 뒤 실행 파일을 다시 열어 주세요.
Mac에서 실행 권한이 없다고 나오면 터미널에 chmod +x 와 공백을 입력한 뒤
실행하기.command 파일을 끌어 넣고 Enter를 누릅니다. 다시 두 번 클릭합니다.

자동 실행이 어려울 때:
Windows에서는 폴더 주소 표시줄에 cmd를 입력하고 Enter를 누른 다음
py -3 -m http.server 8000 을 입력합니다.
Mac에서는 터미널에서 이 폴더로 이동한 뒤 python3 -m http.server 8000 을
입력합니다. 브라우저 주소는 동일합니다.

index.html을 직접 두 번 클릭하면 ES Module 보안 제한 때문에 실행되지
않습니다. Netlify 주소 또는 위 서버 주소로 접속해 주세요.
localhost는 현재 컴퓨터 자신입니다. 다른 컴퓨터나 학생들과 공유할 때는
Netlify의 사이트 주소를 사용해 주세요.

[실험 사용법]
- 홈에서 네 가지 실험 중 하나를 고릅니다. 숫자키 1~4로도 이동합니다.
- 슬라이더를 바꾸고 실행을 누릅니다. 다시 누르면 일시정지합니다.
- 마우스로 드래그하면 시점이 돌아가고 휠을 굴리면 확대됩니다.
- F 키로 전체화면을 전환합니다. 입력창을 쓰는 동안은 단축키가 꺼집니다.
- 별은 현재 브라우저에 저장됩니다. 시크릿 모드에서는 유지되지 않을 수 있습니다.
- 초기화는 현재 실험을 다시 준비합니다. 포물선의 완료된 궤적은 남습니다.
  포물선 궤적은 '궤적 지우기'로 지웁니다.
- 롤러코스터는 위치에너지와 운동에너지가 처음 같아지는 순간 멈춥니다.
  '이어서 실행'을 누르면 계속 움직입니다.

[AI 물리 선생님]
1. 우측 위 톱니바퀴를 누릅니다.
2. Google AI Studio에서 발급한 Gemini API 키를 입력하고 저장합니다.
3. 실험 화면에서 '물리 선생님에게 물어보기'를 누릅니다.
4. 초등·중등·고등을 고르고 질문을 입력합니다. Enter로도 보낼 수 있습니다.
API 키 없이도 네 실험은 실행됩니다.
키는 브라우저에 저장되며 질문할 때 키와 질문·현재 실험 정보가 Google의
Gemini API로 전송됩니다. API 키를 소스나 GitHub에 직접 적지 마세요.
학습 대화는 현재 실행 중에만 유지됩니다. 최근 질문·답변 10쌍을 사용합니다.

모델을 찾을 수 없다는 안내가 나오는 경우:
physics-playground-3d/js/ai-teacher.js 파일의 1번째 줄에서
const GEMINI_MODEL = 'gemini-3.7-flash';
의 모델명을 본인의 Google AI Studio에서 사용 가능한 모델명으로 바꿉니다.
원래 요청한 모델명을 그대로 넣었으며, 계정별 모델 사용 가능 여부와
실제 API 응답은 본인의 API 키로 확인해야 합니다.

[문제 해결]
- 3D 화면 실패: 인터넷 연결과 브라우저 그래픽 가속 설정을 확인합니다.
  cdn.jsdelivr.net 연결이 차단된 기관망에서는 Three.js를 불러올 수 없습니다.
- 포트 사용 중: 이전에 켜 둔 실행 창을 확인합니다. 이 앱의 서버가 이미
  켜져 있다면 새 창을 켤 필요 없이 localhost:8000을 엽니다.
- API 키 오류: 설정에서 키를 삭제한 뒤 새로 입력합니다.
- 요청이 많다는 안내: 잠시 기다린 뒤 다시 질문합니다.

[검증 범위]
수식, 고정 시간 간격, 운동량·에너지 보존, 주기, 미션·초기화·궤적,
JavaScript 문법과 HTTP 응답을 점검했습니다.
작업 브라우저의 WebGL 비활성화로 실제 3D 화면의 시각 검증은 완료하지
못했습니다. 실제 Gemini 응답도 사용자 API 키 없이 확인하지 못했습니다.

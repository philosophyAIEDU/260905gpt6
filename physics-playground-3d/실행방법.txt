물리 놀이터 3D — 1단계 확인용 실행 안내
========================================

현재 완성된 부분: 홈 화면, 포물선 운동, 실험 미션과 별 저장
다음 단계에서 추가할 부분: 충돌, 롤러코스터, 행성 궤도, AI 물리 선생님
두 번 클릭하는 자동 실행 파일은 요청하신 순서대로 5단계에서 추가합니다.

중요: index.html을 두 번 클릭해서 열면 3D 화면이 실행되지 않습니다.
아래처럼 작은 서버를 먼저 켜야 합니다. 인터넷 연결도 필요합니다.

[먼저 다운로드하기]
1. https://github.com/philosophyAIEDU/260905gpt6 를 엽니다.
2. 초록색 Code 버튼 → Download ZIP을 누릅니다.
3. 다운로드한 ZIP 파일의 압축을 풉니다.
4. 안쪽의 physics-playground-3d 폴더를 엽니다.
   index.html, style.css, js 폴더가 보이는 곳입니다.

[Windows에서 켜기]
1. 위 폴더의 맨 위 주소 표시줄을 클릭합니다.
2. cmd 라고 입력하고 Enter 키를 누릅니다.
3. 검은 창에 아래 한 줄을 복사해 넣고 Enter를 누릅니다.

   python3 -m http.server 8000

4. 명령을 찾을 수 없거나 Microsoft Store만 열리면 아래 명령도 확인합니다.

   py -3 -m http.server 8000

5. Serving HTTP 라는 글자가 나오면 성공입니다.
   검은 창을 그대로 두고 Chrome 또는 Edge에서 아래 주소를 엽니다.

   http://localhost:8000

[Mac에서 켜기]
1. 터미널을 엽니다.
2. cd 를 입력한 뒤 공백 한 칸을 넣습니다.
3. physics-playground-3d 폴더를 터미널 창으로 끌어 넣고 Enter를 누릅니다.
4. 아래 명령을 입력하고 Enter를 누릅니다.

   python3 -m http.server 8000

5. 터미널 창을 그대로 두고 브라우저에서 http://localhost:8000 을 엽니다.

[Python이 없다고 나올 때]
https://www.python.org/downloads/ 에서 Python 3를 설치해 주세요.
Windows 설치 화면에 Add Python to PATH 옵션이 보이면 선택합니다.
설치가 끝나면 검은 창 또는 터미널을 닫았다가 위 순서로 다시 엽니다.

[1단계에서 확인해 보세요]
1. 포물선 운동 카드의 '이 실험 하러 가기'를 누릅니다.
2. 기본값(45°, 30 m/s, 지구)에서 실행합니다.
   결과는 최고 높이 약 23.0m, 거리 약 91.8m, 체공 시간 약 4.33초입니다.
3. 초기 속도를 31.3m/s 정도로 맞추면 100m 과녁에 명중합니다.
4. 45°, 30m/s에서 지구 실험을 끝낸 다음, 각도와 속도를 유지하고
   달 버튼을 누른 뒤 실행합니다. 달에서는 약 562.5m를 날아갑니다.
   달에서는 비행에 약 26.52초가 걸립니다.
5. 마우스로 드래그하면 시점이 돌아가고, 휠을 굴리면 확대됩니다.
6. F 키는 전체화면, 1 키는 포물선 실험 바로가기입니다.

[문제가 생겼을 때]
- 브라우저 주소가 file:// 로 시작하면 위 서버 실행 순서를 따라 주세요.
- 3D 화면이 나오지 않으면 인터넷 연결과 브라우저의 그래픽 가속 설정을
  확인해 주세요. 학교나 기관망에서 cdn.jsdelivr.net 연결이 막히면
  Three.js를 불러올 수 없습니다.
- AI 설정과 나머지 실험은 아직 준비 중이라고 표시되는 것이 정상입니다.
- 포트 8000을 이미 사용 중이라는 오류가 나오면 이전에 켠 서버 창을
  확인해 주세요. 이미 이 앱의 서버가 켜져 있다면 그 창을 그대로 두고
  http://localhost:8000 으로 접속하면 됩니다.
- 서버를 끄려면 검은 창이나 터미널에서 Ctrl+C를 누릅니다.

참고: localhost는 지금 브라우저를 사용하는 컴퓨터 자신을 뜻합니다.
개발 작업 환경에서 실행한 서버 주소가 사용자 PC에 자동으로 연결되지는
않습니다. 사용자 PC에서도 위의 서버 켜기 과정을 실행해야 합니다.

[검증 상태]
JavaScript 문법, Python HTTP 응답, 포물선 수식의 경계값,
실제 모듈의 미션·궤적·초기화 로직은 확인했습니다.
개발 작업 환경 브라우저는 WebGL이 비활성화되어 있어 3D 렌더링과
OrbitControls의 실제 화면 동작은 아직 검증하지 못했습니다.

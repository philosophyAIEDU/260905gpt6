# 🚀 물리 놀이터 3D

학생이 직접 조건을 바꾸며 탐구하는 한국어 3D 물리 실험실입니다.
현재는 요청하신 **1단계 확인용 버전**입니다.

## 현재 사용할 수 있는 기능

- 홈 화면과 4개의 실험 카드, 미션별 별 표시
- 포물선 운동: 발사각 0–90°, 초기 속도 5–50m/s, 지구·달·화성 중력
- 1/120초 고정 시간 간격, 수식으로 계산하는 공기저항 없는 운동
- 최고 높이·수평 도달 거리·체공 시간의 실시간 측정
- 서로 다른 색상의 궤적 최대 3개, 일시정지·이어서 실행·초기화
- 과녁 명중 등 3개 미션, 브라우저에 별 저장
- OrbitControls, 화면 크기에 따른 레이아웃, 전체화면 F 키

## 실행하기

**npm 설치나 빌드는 필요 없습니다.** 앱은 `physics-playground-3d/` 안의 HTML/CSS/JS만 사용합니다.

1. **Code → Download ZIP**을 선택하고 압축을 풉니다.
2. 안쪽의 **physics-playground-3d** 폴더를 엽니다.
3. Windows에서는 탐색기 주소 표시줄에 **cmd**를 입력하고 Enter를 누릅니다.
4. 아래 명령을 복사해 넣고 Enter를 누릅니다.

```bash
python3 -m http.server 8000
```

Windows에서 `python3`를 찾지 못하면 `py -3 -m http.server 8000`을 사용합니다.
검은 창을 그대로 두고 **[http://localhost:8000](http://localhost:8000)** 을 엽니다.

Mac과 Python 설치 안내를 포함한 자세한 순서는 [실행방법.txt](physics-playground-3d/실행방법.txt)를 참고해 주세요.
`index.html`을 직접 두 번 클릭하면 ES Module 보안 제한으로 실행되지 않습니다.
인터넷에 연결되어 있어야 CDN에서 Three.js를 불러올 수 있습니다.

## 1단계 확인 예시

| 조건 | 최고 높이 | 도달 거리 | 체공 시간 |
|---|---:|---:|---:|
| 지구 · 45° · 30m/s | 23.0m | 91.8m | 4.33초 |
| 달 · 45° · 30m/s | 140.6m | 562.5m | 26.52초 |

지구에서 45°·31.3m/s로 발사하면 100m 과녁의 ±3m 범위에 들어옵니다.
초기화는 현재 비행을 멈추고 측정값을 초기화하며, 완료된 궤적과 획득한 별은 유지합니다.
과녁 판정은 착지 거리 기준입니다. 0°에서 체공 시간이 0인 것은 발사점과 착지점의 높이가 같은 이상화 조건 때문입니다.

## 작업 순서

1. **현재:** 홈·공통 3D 환경·포물선 운동 구현, 사용자 확인 대기
2. 충돌과 운동량, 롤러코스터 에너지
3. 중력과 행성 궤도
4. Gemini AI 물리 선생님, API 키·학년·기록 설정
5. `실행하기.bat`, `실행하기.command`, 최종 실행 안내와 전체 점검

다음 실험 파일은 구조만 마련되어 있습니다. AI 응답을 흉내 내거나 API 키를 요구하지 않습니다.

## 검증 결과와 제한

- 전체 JavaScript 문법 검사 통과
- Python HTTP 서버에서 HTML, CSS, JS 응답 200 확인
- 포물선 기준값, 상보각 사거리, 지구/달 비율, 0°/90°, 고정 간격 경계값 검사 통과
- 실제 `createProjectile` 모듈의 발사·일시정지·미션·궤적 제한·초기화·자원 정리 등 10개 로직 검사 통과
- 홈 화면과 3D 연결 실패 시 오류 안내의 브라우저 동작 확인
- **작업 환경의 브라우저에서 WebGL이 비활성화되어 있어 실제 3D 렌더링, 카메라 조작, 시각적 반응형 점검은 미완료입니다.**

저장소 루트의 `package.json`, `preview-server.mjs`, `qa/`는 개발 환경의 점검 보조 파일입니다.
학생용 앱 실행에 Node.js나 npm을 설치할 필요는 없습니다. 점검 페이지는 실제 모듈을 불러오지만 WebGL 렌더링 검증을 대신하지 않습니다.

## 수정 위치

- 화면 구조: `physics-playground-3d/index.html`
- 색상·글꼴·버튼·반응형: `physics-playground-3d/style.css`
- 화면 전환·공통 렌더러·단축키·미션 저장: `physics-playground-3d/js/main.js`
- 포물선 수식·과녁·궤적·미션: `physics-playground-3d/js/sims/projectile.js`

Three.js **r160.1**을 CDN ES Module/importmap 방식으로 고정했으며, 물리 엔진 라이브러리를 사용하지 않습니다.
[Three.js OrbitControls 공식 문서](https://threejs.org/docs/pages/OrbitControls.html)를 참고할 수 있습니다.
